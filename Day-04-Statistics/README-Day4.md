# Day 4 – Statistics for Machine Learning

## Topics Covered

- Statistics in Machine Learning
- Population vs Sample
- Mean
- Median
- Mode
- Variance
- Standard Deviation

## Key Takeaways

- Statistics helps us understand data before building models.
- Mean summarizes the average.
- Median is robust to outliers.
- Variance and standard deviation measure data spread.
- Statistical analysis is a key step in every ML workflow.
