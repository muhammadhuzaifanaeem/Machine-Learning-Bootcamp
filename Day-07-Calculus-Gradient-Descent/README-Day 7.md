# Day 7 — Mathematics & Optimization for Machine Learning

## Overview

Day 7 focused on the mathematical foundations behind optimization in Machine Learning.

The objective was to understand how ML models use derivatives and gradients to minimize loss and improve their parameters.

## Topics Covered

- Rate of Change
- Slope
- Tangent Lines
- Derivatives
- Power Rule
- Chain Rule
- Partial Derivatives
- Gradient Vectors
- Gradient Direction
- Cost/Loss Functions
- Gradient Descent
- Learning Rate
- Convergence
- Local vs Global Minimum
- Numerical Derivatives
- Gradient Descent from Scratch
- 2D Loss Surfaces
- Contour Plots
- Gradient Descent Paths

## Practical Work

Implemented:

1. Numerical derivative calculation
2. Gradient Descent from scratch
3. Learning-rate experiments
4. 2D Gradient Descent
5. Loss visualization
6. Contour visualization

## Key Learning

Gradient Descent updates model parameters in the direction opposite to the gradient in order to minimize the loss function.
