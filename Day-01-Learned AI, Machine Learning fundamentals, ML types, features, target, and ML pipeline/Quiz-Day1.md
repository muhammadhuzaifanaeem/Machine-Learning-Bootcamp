# Quiz Day 1 ML Bootcamp

## Q1:Is every AI system a Machine Learning system?
Answer: No, not every AI system is not a ML syatem. ML is just a branch of AI, there are many more branches of AI.

## Q2:Is every Machine Learning system a Deep Learning system?
Answer: No, every ML system is not a DL system.

## Q3:Can Machine Learning work without data?
Answer: ML cannot work without data. Data is the neccessary element for ML.

## Q4:In a house-price dataset, is "price" a feature or the target?
Answer: Its a Target.

## Q5:Which type of ML would you use if you already know the correct answers during training?
Answer: Its Supervised Learning.
